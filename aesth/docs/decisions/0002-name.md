# ADR 0002 — Name: Aesth / aesth / æsth

**Status:** accepted  
**Date:** 19 October 2026

## Context

The public package needed a name that is not Arden-branded, is simple enough for PyPI, and can carry an experimental identity. Working names included `inklane`, `tidemark`, `inkwell`, `quietink`.

## Options

1. `inklane` — ink + swimlane; clear, a little literal.
2. Material names (`vellum`, `carbon`) — better as **palettes** than as the product.
3. **Aesth** / package `aesth` / mark **æsth** — locked in the creative direction brief.

## Choice

Option 3. The ligature `æ` is the mark: aesthetics fused with computation. Official product name remains **Aesth**; import name is `aesth` (ASCII). Tagline: *The aesthetics of data.*

Identity colours for brand chrome (docs, GitHub, monochrome icon), not for data series:

- Near-black `#151515`
- Warm white `#F1F0EB`
- Gray `#989898`

## Consequences

- Folder, package, and docs all use `aesth`.
- Palette names can be material (`vellum`, `obsidian`) without colliding with the product name.
- Custom lettering for the ligature is a later identity sprint, not a blocker for themes.
